# 物语

Monogatari Novel — приложение для чтения романов и электронных книг, созданное на основе [Anx Reader](https://github.com/Anxcye/anx-reader).

Сохранены [лицензия MIT](LICENSE) исходного проекта и сведения об авторах. Лицензии сторонних компонентов находятся рядом с соответствующими файлами. Благодарим авторов Anx Reader, [foliate-js](https://github.com/johnfactotum/foliate-js) и [других открытых зависимостей](pubspec.yaml).

Установочные файлы и описание версий доступны в [GitHub Releases](https://github.com/Teikaraku/monogatari-novel/releases/latest):

- Android: [подписанный универсальный APK](https://github.com/Teikaraku/monogatari-novel/releases/latest/download/Monogatari-Novel-Android-universal.apk).
- iOS: [неподписанный IPA](https://github.com/Teikaraku/monogatari-novel/releases/latest/download/Monogatari-Novel-iOS-unsigned.ipa). Перед установкой его необходимо подписать самостоятельно.

Официальные версии собираются и публикуются через GitHub Actions по тегам версий. При каждом запуске приложение один раз проверяет GitHub `releases/latest` этого репозитория. Проверить обновления вручную можно в настройках.

В общедоступной версии по умолчанию не настроен адрес собственного сервера библиотеки; данные библиотеки и ключи доступа не включены. Можно импортировать и читать локальные электронные книги. Для онлайн-библиотеки необходимо настроить собственный сервис и заново собрать приложение.
