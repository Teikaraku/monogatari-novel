# 物语

Monogatari Novel, [Anx Reader](https://github.com/Anxcye/anx-reader) temel alınarak geliştirilen bir roman ve e-kitap okuyucusudur.

Üst projenin [MIT lisansı](LICENSE) ve yazar bilgileri korunmuştur. Üçüncü taraf bileşenlerin lisansları ilgili dosyalarla birlikte saklanır. Anx Reader, [foliate-js](https://github.com/johnfactotum/foliate-js) ve [diğer açık kaynak bağımlılıkların](pubspec.yaml) yazarlarına teşekkürler.

Kurulum dosyaları ve sürüm notları [GitHub Releases](https://github.com/Teikaraku/monogatari-novel/releases/latest) sayfasındadır:

- Android: [İmzalı evrensel APK](https://github.com/Teikaraku/monogatari-novel/releases/latest/download/Monogatari-Novel-Android-universal.apk).
- iOS: [İmzasız IPA](https://github.com/Teikaraku/monogatari-novel/releases/latest/download/Monogatari-Novel-iOS-unsigned.ipa). Kurmadan önce kendiniz imzalamanız gerekir.

Resmî sürümler, sürüm etiketleri üzerinden GitHub Actions ile derlenip yayımlanır. Uygulama her açılışta bu deponun GitHub `releases/latest` uç noktasını bir kez kontrol eder. Ayarlardan güncellemeleri elle de kontrol edebilirsiniz.

Herkese açık sürümde varsayılan bir özel kitaplık sunucusu adresi, kitaplık verisi veya erişim anahtarı bulunmaz. Yerel e-kitapları içe aktararak okuyabilirsiniz. Çevrim içi kitaplık için kendi hizmetinizi yapılandırıp uygulamayı yeniden derlemeniz gerekir.
